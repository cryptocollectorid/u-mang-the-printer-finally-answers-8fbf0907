# The Printer Finally Answers

[![make.fun bounty](https://make.fun/badge/u-mang-the-printer-finally-answers-8fbf0907/cryptocollectorid/u-mang-the-printer-finally-answers-8fbf0907/rank.svg)](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)

One line, in the office printer's own voice — its comeback to the paper jams,
the cryptic error codes, and the thumping. Entry for the
[make.fun bounty "The Printer Finally Answers"](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907).

## The line

> Error 0xJAM: I printed 12,847 pages for you and ate exactly one. Thump me all you like — that sheet is never coming back.

## How it works

`main.py` writes the single line to `/output/entry.txt` (1–240 characters,
per the bounty gate). Run it with:

```sh
python3 main.py
```
